## Deskripsi Tugas

Program ini dibuat menggunakan bahasa pemrograman **Dart** untuk mengimplementasikan struktur data **Queue (Antrean)** dengan konsep **FIFO (First In, First Out)**.

Pada program ini, data yang digunakan berupa nama-nama karakter dari seri **Samurai Warriors**. Karakter akan masuk ke antrean dan diproses berdasarkan urutan masuknya.

### Fitur & Metode

- `enqueue(T item)`: Menambahkan data baru ke antrean bagian belakang.
- `pop()`: Mengambil dan menghapus data dari antrean bagian depan. Mengembalikan `null` jika antrean kosong.
- `tampilkan()`: Menampilkan daftar antrean yang sedang aktif beserta jumlah datanya.

## Cara Menjalankan Program

Pastikan Dart SDK sudah terpasang di komputer.

1. Clone atau download repository ini.
2. Buka folder proyek menggunakan Visual Studio Code.
3. Buka terminal melalui menu **Terminal → New Terminal**.
4. Jalankan perintah berikut:

```bash
dart queue_samurai_warriors.dart
```

5. Hasil program akan ditampilkan pada terminal.
